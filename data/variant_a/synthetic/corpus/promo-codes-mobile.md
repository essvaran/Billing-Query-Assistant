# Apply a promo code (mobile)

## Overview

Why a promo code may not apply to your cart in the mobile app. This article applies to all accounts unless a section says otherwise.
The promo code is issued within 15 minutes and stays valid for 3 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the promo codes option in the mobile app.
3. Confirm your identity if asked, then submit the promo code request.
4. Wait up to 15 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 12 |
| Promo code valid for | 3 days |
| Typical completion time | 15 minutes |

## Troubleshooting

If you see error code ERR-1206, wait 15 minutes and try again. If the error persists after
12 attempts the request is locked and you should contact support with the code ERR-1206.
