# Create and rotate API keys (troubleshooting)

## Overview

Issue, scope and rotate keys when something goes wrong. This article applies to all accounts unless a section says otherwise.
The API key is issued within 10 minutes and stays valid for 9 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the api keys option when something goes wrong.
3. Confirm your identity if asked, then submit the API key request.
4. Wait up to 10 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 6 |
| Api key valid for | 9 days |
| Typical completion time | 10 minutes |

## Troubleshooting

If you see error code ERR-9279, wait 10 minutes and try again. If the error persists after
6 attempts the request is locked and you should contact support with the code ERR-9279.
