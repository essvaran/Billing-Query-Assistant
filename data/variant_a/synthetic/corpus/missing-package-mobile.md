# Package marked delivered but missing (mobile)

## Overview

Steps when tracking says delivered in the mobile app. This article applies to all accounts unless a section says otherwise.
The investigation is issued within 60 minutes and stays valid for 2 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the missing package option in the mobile app.
3. Confirm your identity if asked, then submit the investigation request.
4. Wait up to 60 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 3 |
| Investigation valid for | 2 days |
| Typical completion time | 60 minutes |

## Troubleshooting

If you see error code ERR-3433, wait 60 minutes and try again. If the error persists after
3 attempts the request is locked and you should contact support with the code ERR-3433.
