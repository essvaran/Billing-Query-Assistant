# Use and check gift cards (web)

## Overview

Redeem a gift card and check the balance on the website. This article applies to all accounts unless a section says otherwise.
The gift card code is issued within 5 minutes and stays valid for 5 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the gift cards option on the website.
3. Confirm your identity if asked, then submit the gift card code request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 10 |
| Gift card code valid for | 5 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-9560, wait 5 minutes and try again. If the error persists after
10 attempts the request is locked and you should contact support with the code ERR-9560.
