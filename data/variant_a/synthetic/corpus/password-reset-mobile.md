# Reset your password (mobile)

## Overview

Reset a forgotten or expired password in the mobile app. This article applies to all accounts unless a section says otherwise.
The reset link is issued within 30 minutes and stays valid for 2 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the password reset option in the mobile app.
3. Confirm your identity if asked, then submit the reset link request.
4. Wait up to 30 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 3 |
| Reset link valid for | 2 days |
| Typical completion time | 30 minutes |

## Troubleshooting

If you see error code ERR-8355, wait 30 minutes and try again. If the error persists after
3 attempts the request is locked and you should contact support with the code ERR-8355.
