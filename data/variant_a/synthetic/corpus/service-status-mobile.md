# Check service status (mobile)

## Overview

Where to see incidents and maintenance in the mobile app. This article applies to all accounts unless a section says otherwise.
The status page is issued within 5 minutes and stays valid for 6 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the service status option in the mobile app.
3. Confirm your identity if asked, then submit the status page request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 11 |
| Status page valid for | 6 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-6165, wait 5 minutes and try again. If the error persists after
11 attempts the request is locked and you should contact support with the code ERR-6165.
