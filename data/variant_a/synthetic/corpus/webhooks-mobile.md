# Set up webhooks (mobile)

## Overview

Receive event notifications at your endpoint in the mobile app. This article applies to all accounts unless a section says otherwise.
The webhook endpoint is issued within 30 minutes and stays valid for 9 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the webhooks option in the mobile app.
3. Confirm your identity if asked, then submit the webhook endpoint request.
4. Wait up to 30 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 7 |
| Webhook endpoint valid for | 9 days |
| Typical completion time | 30 minutes |

## Troubleshooting

If you see error code ERR-7697, wait 30 minutes and try again. If the error persists after
7 attempts the request is locked and you should contact support with the code ERR-7697.
