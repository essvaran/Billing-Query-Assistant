# Control notifications (web)

## Overview

Choose which emails and alerts you get on the website. This article applies to all accounts unless a section says otherwise.
The notification setting is issued within 60 minutes and stays valid for 9 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the notifications option on the website.
3. Confirm your identity if asked, then submit the notification setting request.
4. Wait up to 60 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 8 |
| Notification setting valid for | 9 days |
| Typical completion time | 60 minutes |

## Troubleshooting

If you see error code ERR-5909, wait 60 minutes and try again. If the error persists after
8 attempts the request is locked and you should contact support with the code ERR-5909.
