# Reset your password (web)

## Overview

Reset a forgotten or expired password on the website. This article applies to all accounts unless a section says otherwise.
The reset link is issued within 15 minutes and stays valid for 4 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the password reset option on the website.
3. Confirm your identity if asked, then submit the reset link request.
4. Wait up to 15 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 5 |
| Reset link valid for | 4 days |
| Typical completion time | 15 minutes |

## Troubleshooting

If you see error code ERR-4175, wait 15 minutes and try again. If the error persists after
5 attempts the request is locked and you should contact support with the code ERR-4175.
