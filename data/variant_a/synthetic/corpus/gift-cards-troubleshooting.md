# Use and check gift cards (troubleshooting)

## Overview

Redeem a gift card and check the balance when something goes wrong. This article applies to all accounts unless a section says otherwise.
The gift card code is issued within 10 minutes and stays valid for 8 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the gift cards option when something goes wrong.
3. Confirm your identity if asked, then submit the gift card code request.
4. Wait up to 10 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 11 |
| Gift card code valid for | 8 days |
| Typical completion time | 10 minutes |

## Troubleshooting

If you see error code ERR-8609, wait 10 minutes and try again. If the error persists after
11 attempts the request is locked and you should contact support with the code ERR-8609.
