# Set up two-factor authentication (web)

## Overview

Protect your account with a second sign-in step on the website. This article applies to all accounts unless a section says otherwise.
The verification code is issued within 30 minutes and stays valid for 9 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the two factor option on the website.
3. Confirm your identity if asked, then submit the verification code request.
4. Wait up to 30 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 7 |
| Verification code valid for | 9 days |
| Typical completion time | 30 minutes |

## Troubleshooting

If you see error code ERR-6402, wait 30 minutes and try again. If the error persists after
7 attempts the request is locked and you should contact support with the code ERR-6402.
