# Change the delivery address (web)

## Overview

Edit the address before the parcel ships on the website. This article applies to all accounts unless a section says otherwise.
The address change is issued within 10 minutes and stays valid for 5 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the change address option on the website.
3. Confirm your identity if asked, then submit the address change request.
4. Wait up to 10 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 3 |
| Address change valid for | 5 days |
| Typical completion time | 10 minutes |

## Troubleshooting

If you see error code ERR-9174, wait 10 minutes and try again. If the error persists after
3 attempts the request is locked and you should contact support with the code ERR-9174.
