# Use and check gift cards (mobile)

## Overview

Redeem a gift card and check the balance in the mobile app. This article applies to all accounts unless a section says otherwise.
The gift card code is issued within 30 minutes and stays valid for 4 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the gift cards option in the mobile app.
3. Confirm your identity if asked, then submit the gift card code request.
4. Wait up to 30 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 4 |
| Gift card code valid for | 4 days |
| Typical completion time | 30 minutes |

## Troubleshooting

If you see error code ERR-3490, wait 30 minutes and try again. If the error persists after
4 attempts the request is locked and you should contact support with the code ERR-3490.
