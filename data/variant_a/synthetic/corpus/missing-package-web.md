# Package marked delivered but missing (web)

## Overview

Steps when tracking says delivered on the website. This article applies to all accounts unless a section says otherwise.
The investigation is issued within 30 minutes and stays valid for 7 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the missing package option on the website.
3. Confirm your identity if asked, then submit the investigation request.
4. Wait up to 30 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 3 |
| Investigation valid for | 7 days |
| Typical completion time | 30 minutes |

## Troubleshooting

If you see error code ERR-4000, wait 30 minutes and try again. If the error persists after
3 attempts the request is locked and you should contact support with the code ERR-4000.
