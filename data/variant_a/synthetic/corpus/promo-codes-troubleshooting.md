# Apply a promo code (troubleshooting)

## Overview

Why a promo code may not apply to your cart when something goes wrong. This article applies to all accounts unless a section says otherwise.
The promo code is issued within 5 minutes and stays valid for 4 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the promo codes option when something goes wrong.
3. Confirm your identity if asked, then submit the promo code request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 6 |
| Promo code valid for | 4 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-4489, wait 5 minutes and try again. If the error persists after
6 attempts the request is locked and you should contact support with the code ERR-4489.
