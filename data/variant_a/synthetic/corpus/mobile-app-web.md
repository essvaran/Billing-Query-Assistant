# Use the mobile app (web)

## Overview

Install and sign in on a phone on the website. This article applies to all accounts unless a section says otherwise.
The app sign-in is issued within 5 minutes and stays valid for 6 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the mobile app option on the website.
3. Confirm your identity if asked, then submit the app sign-in request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 3 |
| App sign-in valid for | 6 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-1194, wait 5 minutes and try again. If the error persists after
3 attempts the request is locked and you should contact support with the code ERR-1194.
