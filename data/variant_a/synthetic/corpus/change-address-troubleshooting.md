# Change the delivery address (troubleshooting)

## Overview

Edit the address before the parcel ships when something goes wrong. This article applies to all accounts unless a section says otherwise.
The address change is issued within 5 minutes and stays valid for 7 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the change address option when something goes wrong.
3. Confirm your identity if asked, then submit the address change request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 7 |
| Address change valid for | 7 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-8539, wait 5 minutes and try again. If the error persists after
7 attempts the request is locked and you should contact support with the code ERR-8539.
