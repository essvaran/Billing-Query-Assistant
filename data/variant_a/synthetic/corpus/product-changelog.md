# Product Changelog

Added webhook retry dashboard and CSV export for invoices.

Mobile app now supports biometric sign-in.

## Release 2026.08 (2026-07-26)

Express shipping added for Australia and Asia Pacific.

## Release 2026.07 (2026-06-28)

Team plans can now reassign seats without support.

## Release 2026.06 (2026-05-31)

Promo code stacking rules clarified; one code per order.

## Release 2026.05 (2026-04-26)

Shipping SLA matrix refreshed for all six regions.

Loyalty points now expire after 18 months.

Refund window extended from 14 days to 30 days for new and migrated accounts. Legacy accounts keep the 14-day window until they are migrated.
