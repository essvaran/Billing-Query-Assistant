# Create and rotate API keys (web)

## Overview

Issue, scope and rotate keys on the website. This article applies to all accounts unless a section says otherwise.
The API key is issued within 5 minutes and stays valid for 8 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the api keys option on the website.
3. Confirm your identity if asked, then submit the API key request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 10 |
| Api key valid for | 8 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-1698, wait 5 minutes and try again. If the error persists after
10 attempts the request is locked and you should contact support with the code ERR-1698.
