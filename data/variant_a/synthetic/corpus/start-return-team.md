# Start a return (team)

## Overview

Request a return label for an eligible item for team and business accounts. This article applies to all accounts unless a section says otherwise.
The return label is issued within 5 minutes and stays valid for 5 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the start return option for team and business accounts.
3. Confirm your identity if asked, then submit the return label request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 11 |
| Return label valid for | 5 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-6782, wait 5 minutes and try again. If the error persists after
11 attempts the request is locked and you should contact support with the code ERR-6782.
