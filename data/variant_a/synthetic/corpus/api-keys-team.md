# Create and rotate API keys (team)

## Overview

Issue, scope and rotate keys for team and business accounts. This article applies to all accounts unless a section says otherwise.
The API key is issued within 10 minutes and stays valid for 7 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the api keys option for team and business accounts.
3. Confirm your identity if asked, then submit the API key request.
4. Wait up to 10 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 8 |
| Api key valid for | 7 days |
| Typical completion time | 10 minutes |

## Troubleshooting

If you see error code ERR-7809, wait 10 minutes and try again. If the error persists after
8 attempts the request is locked and you should contact support with the code ERR-7809.
