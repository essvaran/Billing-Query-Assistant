# Apply a promo code (web)

## Overview

Why a promo code may not apply to your cart on the website. This article applies to all accounts unless a section says otherwise.
The promo code is issued within 60 minutes and stays valid for 5 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the promo codes option on the website.
3. Confirm your identity if asked, then submit the promo code request.
4. Wait up to 60 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 5 |
| Promo code valid for | 5 days |
| Typical completion time | 60 minutes |

## Troubleshooting

If you see error code ERR-3478, wait 60 minutes and try again. If the error persists after
5 attempts the request is locked and you should contact support with the code ERR-3478.
