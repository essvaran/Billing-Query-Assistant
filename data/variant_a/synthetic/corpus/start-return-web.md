# Start a return (web)

## Overview

Request a return label for an eligible item on the website. This article applies to all accounts unless a section says otherwise.
The return label is issued within 5 minutes and stays valid for 5 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the start return option on the website.
3. Confirm your identity if asked, then submit the return label request.
4. Wait up to 5 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 9 |
| Return label valid for | 5 days |
| Typical completion time | 5 minutes |

## Troubleshooting

If you see error code ERR-7865, wait 5 minutes and try again. If the error persists after
9 attempts the request is locked and you should contact support with the code ERR-7865.
