# Report a damaged item (mobile)

## Overview

What to do when an item arrives damaged in the mobile app. This article applies to all accounts unless a section says otherwise.
The damage report is issued within 60 minutes and stays valid for 3 days.

## Steps

1. Sign in and open Account Settings.
2. Choose the damaged item option in the mobile app.
3. Confirm your identity if asked, then submit the damage report request.
4. Wait up to 60 minutes for the confirmation.

## Limits and timing

| Item | Value |
|---|---|
| Requests allowed per day | 5 |
| Damage report valid for | 3 days |
| Typical completion time | 60 minutes |

## Troubleshooting

If you see error code ERR-5878, wait 60 minutes and try again. If the error persists after
5 attempts the request is locked and you should contact support with the code ERR-5878.
