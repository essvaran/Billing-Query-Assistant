The pattern: orchestrator and workers

Orchestrator (manager)
Splits the job, hands pieces to specialists, verifies the draft against its sources, returns the final reply or an explicit refusal. 1 LLM call.
Triage worker
Narrow prompt, no tools. Normalizes codes (error 4032 becomes ERR-4032), classifies intent, rewrites the search query. Skipped when the question has no code to normalize, so the original wording is searched. 1 LLM call.
Policy-lookup worker
Narrow prompt, one tool (hybrid search). Retries the tool once on failure, then drafts a cited answer. 1 LLM call.
Why it can cost more: every hand-off re-sends context (question, chunks, draft), so tokens multiply.
MCP vs A2A: MCP connects an agent to tools. A2A connects an agent to other agents.
When a team genuinely helps: independent sub-tasks that can run in parallel, or parts needing clearly different instructions.
